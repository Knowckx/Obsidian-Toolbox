## Markdown 表格转置

状态：已实现，已在源码模式和实时预览模式中验证。

- 命令 ID：`transpose-markdown-table`
- 命令名称：`Transpose Markdown table`
- 默认快捷键：无
- 触发条件：光标位于合法 Markdown 表格内部

处理流程：

```text
执行命令
→ 定位完整表格源码范围
→ 删除 Markdown 分隔行
→ 转置单元格矩阵
→ 重新生成分隔行
→ 原地替换表格
```

规则：

- Markdown 分隔行不参与转置。
- 未转义的 `|` 作为列分隔符，`\|` 保留为单元格内容。
- 缺少的单元格使用空单元格补齐。
- 输出列对齐统一使用 `---`。
- 找不到合法表格时显示 Notice，文档保持不变。
